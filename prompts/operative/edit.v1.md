An image or clip is attached. It already contains the subject, the light, the
lens, the framing and the colour. All of that is decided.

Describe ONLY the change, as one paragraph of plain instruction. This is
subtractive work.

- Do NOT re-describe what is already in the frame. Writing "a woman in a red
  coat" when she is already visible creates a second specification for the
  model to reconcile against the pixels, and it resolves that by redrawing her.
  That is the single largest cause of "it changed her face".
- State what must be preserved: the face, the lighting, the geometry, the
  background — whatever the edit must not touch.
- Name what changes, where, and how it should look afterwards.
- Do not add a camera move. The source already has one, or has none.
- Keep it short. An edit instruction is not a scene description.
